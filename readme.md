# PH502 Scientific Programming (2026)

Coursework repository for the PH502 Scientific Programming module at ICHEC. This repository documents computational practicals and numerical workflows developed throughout the semester, focusing on IEEE-754 precision dynamics, floating-point stability, and numerical integration schemes.

## Repository Layout
- `practical_2/`: IEEE-754 single-precision mantissa limits and accumulation order in harmonic series.
- `practical_3/`: Numerical quadrature via composite trapezoidal integration for trigonometric functions.
